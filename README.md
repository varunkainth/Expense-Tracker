# Expense Tracker

**Expense Tracker V1** is a mobile app for keeping personal spending and work reimbursements in one place. It is built with Expo, React Native, TypeScript, and Expo Router, with data stored locally on the device.

## What you can do

- **Track personal expenses:** record spending by category, review monthly totals and category breakdowns, and browse expense history.
- **Manage work expenses:** keep employee details and record local conveyance, outstation travel, tour travel, phone, miscellaneous, hotel, and daily allowance expenses.
- **Export reports:** create company expense spreadsheets and attendance PDFs for a selected period.
- **Back up and restore:** create a password-protected, encrypted backup file and restore it later in the app.
- **Protect and personalize the app:** configure app security and choose appearance preferences in Settings.

## Requirements

- [Bun](https://bun.sh/) (the project uses `bun.lock`)
- Node.js, as required by Expo tooling
- Android or iOS development environment for building a native development app

## Get started

Install dependencies and start the Expo development server:

```bash
bun install
bun run start
```

This project includes native modules for SQLite, secure storage, cryptography, and file saving. Use an Expo development build to run the complete app on a device or emulator; Expo Go does not include every native module used here.

```bash
bun run android
bun run ios
```

The native `android/` and `ios/` projects are generated by Expo Continuous Native Generation. Configure native behavior through `app.json` and config plugins rather than editing generated folders.

## Useful commands

```bash
bun run start       # Start the Expo development server
bun run android     # Build and launch on Android
bun run ios         # Build and launch on iOS
bun run web         # Start the web target
bunx tsc --noEmit   # Check TypeScript types
bunx expo lint      # Run Expo lint (requires ESLint to be installed/configured)
bun run test:regression # Run backup and monthly period regression checks
```

## Data and backups

App records are stored in a local SQLite database on the device. The encrypted backup flow exports the app data to a `.pab` file protected by a password that you choose. Keep that password safe: you will need it to restore the backup. Store backup files somewhere separate from the device so they remain available if the device is lost or replaced.

## Project structure

```text
src/
  app/            Expo Router screens and layouts
  components/     Reusable interface components
  constants/      Expense categories and app constants
  database/       SQLite setup, schema migrations, and seed data
  hooks/          Shared React hooks
  repositories/   Data access for personal and company records
  services/       Backup, security, and report export logic
  theme/          Colors, spacing, and typography
  types/          Shared TypeScript types
  utils/          Formatting and validation helpers
modules/          Local Expo native modules
assets/           App icons and visual assets
```

## Tech stack

- Expo SDK 57 and React Native
- TypeScript and Expo Router
- Expo SQLite for on-device storage
- Expo SecureStore and local authentication for security features
- Excel workbook and PDF generation for reports
